Карман 1.0.1 — пакет исходных изменений

Не содержит подпись/ключ, базу данных пользователя или данные о счетах.

1. Загрузите сам ZIP Karman-1.0.1-upgrade.zip в КОРЕНЬ GitHub-репозитория, НЕ распаковывая.
2. Замените .github/workflows/android.yml файлом из второго вложения.
3. После коммита GitHub Actions применит изменения в рабочей копии, запустит тесты, lint и создаст APK.
4. При успешной сборке скачайте артефакт Karman-1.0.1-applied-source: он содержит полные файлы для постоянного сохранения в GitHub.
5. Для обновления установленной подписанной 1.0.0 используйте только RELEASE-signed APK, собранный с ТЕМ ЖЕ закрытым ключом.

Новый код: поиск по истории, фильтр текущего/прошлого месяца, запоминание категорий расхода и дохода по отдельности, удаление шаблонов с подтверждением, тест сохранения операций после удаления шаблона, постоянные исправления компиляции.

Примечание: исходники GitHub остаются прежними до ручной замены файлами из артефакта; изменения автоматически применяются во время CI. VersionCode=2, VersionName=1.0.1, minSdk=26; база данных karman_v1.db не пересоздаётся.
