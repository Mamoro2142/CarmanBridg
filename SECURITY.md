# Подпись и безопасность данных

Новый пакет: `com.mamoro.karman`. Собственный ключ: `karman-release` в контейнере PKCS12 (.p12), RSA 3072 SHA256, срок 10.11.2026–28.03.2054.

Файл ключа и пароль не должны попадать в репозиторий или в переписку по публичным ссылкам. Закрытый комплект передан отдельно; GitHub Actions использует Actions secrets. При публикации исходников убедитесь, что `.p12`, `GitHub-secrets-PRIVATE.txt` и другие файлы с секретами исключены.

Релизный APK предназначен для установки и последующих обновлений. `debug` APK от каждого нового workflow может иметь другой ключ и не подходит для стабильных обновлений.

Приложение хранит свою SQLite-базу в приватной директории Android. Автоматический Android Backup отключён. Экспорт JSON содержит финансовые данные **в открытом виде**: сохраняйте только в доверенном месте и не пересылайте третьим лицам. Внутри приложения пока нет шифрования резервных копий и PIN-блокировки.
