# GitHub только с Android-телефона

## Вариант А — предпочтительный (файлы видны в GitHub)

Создать **новый** репозиторий `Karman`, загрузить содержимое архива `Karman-1.0.0-source.zip` с сохранением папок, включая скрытую `.github/workflows/`. Не надо загружать старый Koshelek 1.11.2. Не надо загружать приватный файл `.p12` и `GitHub-secrets-PRIVATE.txt`.

## Вариант Б — упрощённый для телефона (только два файла)

1. На github.com создать новый приватный репозиторий `Karman`.
2. Загрузить в корень файлом **`Karman-1.0.0-source.zip`** (не распаковывать).
3. Через **Add file → Create new file** создать путь `.github/workflows/android.yml` и вставить содержимое отдельного файла `android.yml`, который предоставлен вместе с исходниками.
4. В **Settings → Secrets and variables → Actions → New repository secret** добавить четыре записи из личного файла `GitHub-secrets-PRIVATE.txt`. Никогда не публиковать текст этих записей и сам `.p12`.
5. Запустить workflow: **Actions → Karman Android — test and build → Run workflow**.
6. При зелёном результате скачать из Artifacts **`Karman-1.0.0-RELEASE-signed`** и установить `app-release.apk`.

Этот вариант позволяет собрать APK без ПК, но исходники лежат внутри ZIP. В будущем лучше хранить файлы отдельными файлами в GitHub, чтобы видеть изменения и делать отдельные коммиты.

**Прошлый «Кошелёк» не изменится и не удалится.** Новое приложение не устанавливается поверх `com.koshelek.app`; оно будет существовать рядом.
